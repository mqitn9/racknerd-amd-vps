## RackNerd AMD VPS 和普通 KVM VPS，差别在哪？

RackNerd 自己有两条 Linux VPS 产品线：标准 KVM VPS 用 Intel Xeon 处理器配 RAID-10 SATA SSD，AMD VPS（也就是 Ryzen 线）用 Ryzen 3900X 或 7950X 配纯 NVMe。两条线都是 KVM 虚拟化、独立 IPv4、1Gbps 端口、SolusVM 面板加完整 root 权限，虚拟化层面没区别，差别全在硬件上。

3900X 是 12 核 24 线程的 7nm 处理器，单核性能比托管环境里常见的旧款 Xeon 强不少。官方页面有句挺大胆的说法——一个 Ryzen 核心抵多个 Xeon 核心——听着像营销话术，但单线程频率的差距是实打实的，尤其你买到的是被切成十几份的老 Xeon vCPU 时。磁盘那头差距更直观：NVMe 阵列的读写能跑到 1 GB/s 以上，SATA SSD 一般只有几百 MB。

同一个价格下，两条线其实是拿存储换性能。以 $17.99/月这一档为例：KVM 线给 2 核、1 GB 内存、50 GB SSD；Ryzen 线给 1 核、1 GB 内存、15 GB NVMe。要大硬盘放文件，KVM 更划算；要数据库响应快、编译快，Ryzen 线的配置对得更准。
